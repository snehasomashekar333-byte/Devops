# Exercise 2: Flask Application with Kubernetes
## Aim
To containerize a Flask application using Docker and deploy it on Kubernetes using a Deployment.
## Tools Used
- Python and Flask
- Docker
- Kubernetes
- Minikube
- kubectl
## Files
- `app.py` - Flask application code
- `Dockerfile` - Instructions to build the Docker image
- `deployment.yaml` - Kubernetes Deployment configuration
- `output.txt` - Recorded exercise output
## Procedure
1. Develop the Flask application.
2. Build a Docker image using the Dockerfile.
3. Configure the Kubernetes Deployment.
4. Deploy the application to Kubernetes.
5. Verify the deployment and application status using kubectl.
## Result
This exercise demonstrates how to package a Flask application in a Docker image and deploy it using Kubernetes.
