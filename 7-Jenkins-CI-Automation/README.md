# Exercise 7: Jenkins CI Automation
## Aim
To understand how Jenkins can automate a Continuous Integration (CI) workflow.
## Tool Used
- Jenkins
## Overview
Jenkins is an automation server that helps build, test, and integrate software changes. A CI workflow can automatically run tasks when changes are made to a project.
## Procedure
1. Set up Jenkins.
2. Create or configure a Jenkins job.
3. Configure the required build steps.
4. Run the job and review the console output.
5. Verify the job status.
## Result
This exercise introduces Jenkins-based automation for a Continuous Integration workflow.
