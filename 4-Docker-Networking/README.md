# Exercise 4: Docker Networking
## Aim
To understand Docker networking and how containers communicate with one another.
## Tools Used
- Docker
- Python
## Overview
Docker networking enables containers to communicate with other containers and external networks. Docker provides different network configurations depending on the communication and isolation requirements of an application.
## Files
- `app.py` - Application code
- `Dockerfile` - Instructions for building the Docker image
- `requirements.txt` - Python dependencies
- `outputs/` - Saved command outputs and logs
- `screenshots/` - Exercise screenshots
## Procedure
1. Review the application code and Dockerfile.
2. Review the required Python dependencies.
3. Examine the Docker network configuration used in the exercise.
4. Review the saved command outputs and screenshots.
5. Verify the results against the exercise instructions.
## Result
This exercise introduces Docker networking concepts and container communication.
