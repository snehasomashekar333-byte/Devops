# Exercise 6: Grafana Real-Time Monitoring of a Quick-Commerce App
## Aim
To understand how application and infrastructure metrics can be monitored using Prometheus and Grafana.
## Tools Used
- Docker
- Jenkins
- Prometheus
- Grafana
- Python
## Overview
Monitoring helps track application performance and identify problems. Prometheus collects and stores metrics, while Grafana can display metrics through dashboards. Jenkins can automate parts of the build and deployment workflow.
## Files
- `delivery_metrics.py` - Python metrics-related application code
- `prometheus.yml` - Prometheus configuration
- `alert_rules.yml` - Alerting rules configuration
- `Jenkinsfile` - Jenkins pipeline configuration
- `outputs/` - Saved command outputs and logs
- `screenshots/` - Exercise screenshots
## Procedure
1. Review the monitoring application and configuration files.
2. Configure Prometheus to collect the required metrics.
3. Review the alert rules.
4. Use Grafana dashboards to visualize available metrics.
5. Review the relevant logs and verify the monitoring setup.
## Result
This exercise demonstrates the configuration and concepts involved in monitoring a quick-commerce application using Prometheus and Grafana.
